# Resident Evil 2 Remake — Online Co-op

An experimental free online co-op project based on the existing
Local Couch Co-op mod for Resident Evil 2 Remake (2019).

## Goals

- Preserve existing Local Couch Co-op gameplay where possible.
- Explore online play between Linux (Steam + Proton) and Windows 11.
- Avoid paid services, subscriptions, and rented servers.
- Keep all development files separate from the game installation.
- Do not modify game files or saves without explicit permission.
